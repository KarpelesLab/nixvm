# The root images this version of nixvm pins: what `ImageRef::released` knows,
# and what `nixvm::image::fetch` downloads and verifies.
#
# Written by the "Root images" workflow (.github/workflows/images.yml), which
# builds the images, publishes them as a GitHub release and attaches this file
# to it as `pinned.txt`. To move nixvm to a new image release, replace this
# file with that release's `pinned.txt` (scripts/pin-images.sh <tag> does it)
# and commit; the next nixvm release then ships the new pins.
#
# Format: a `release <tag>` line, then one line per image:
#   <name> <alpine version> <arch> <sha256> <size in bytes>
# The image is <name>-<alpine version>-<arch>.sqfs among the release's assets.
#
# No image release has been made yet: until the first one, there are no pins.
